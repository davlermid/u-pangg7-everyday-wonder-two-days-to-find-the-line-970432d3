One sentence, at most 200 characters, on a small moment of wonder in everyday life.

> My shadow slipped off the kerb and walked home without me.

The program (`main.ts`) writes that single sentence to `/output/entry.txt`
as UTF-8, with no trailing newline.

## Run

```sh
node main.ts
```
